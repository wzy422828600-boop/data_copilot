# 财务数据与简单经营分析升级

## 本轮完成

保留原2023—2024年顾客、商品、订单及明细，追加2025—2026年10月订单。建立按订单的结算数据和按月的财务项目表，生成利润表、资产负债表、现金流量表及简化权益变动表。

- 全部合成：虚构企业“青禾零售”，46个月、64个项目。
- 11,557笔订单、28,957条订单明细、2,963条报表金额记录。
- 金额在底层使用整数分；界面以人民币元及两位小数展示，可导出CSV。
- 2022-12期初余额用于年初对照；现金流期初和期末不能按月份累加。

## 不是只加一个净利润字段

项目字典记录报表项目、父级小计、流量/余额属性及常见别名。提问会选择项目和期间，再按属性汇总。支持更换月份、年份、季度、同比/比较期、项目和部分指标组合；不能承诺理解任意表述。

报表页提供期末与年初余额，本期、本年累计和上年同期金额；费用明细保留“其中”层级。权益表只展示未分配利润的期初、本期净利润、分红与期末衔接，不作为完整法定权益报表。

## 已能完成的简单分析

- 销售变化：两期销售额、订单、客单价、销量；订单数/客单价对称分解；渠道和品类各自的变化贡献。
- 净利润变化：收入、成本、费用和所得税的贡献，合计对齐净利润变化。
- 利润与经营现金流差额：折旧、筹资利息分类、应收/存货/应付/税费变动逐项衔接。
- 财务取数、趋势、期间比较及利润率、费用率、负债率、流动/速动比率。
- 成交额与营业收入差额：模拟退款的对照，不把退款前成交额混作报表收入。

这只解释数值变化，未验证真实经营原因。模拟的2026-10对2026-09销售额下降20.42%，净利润反而略有增加，程序会按实际记录回答，不跟随问题的错误前提。

## 主要简化

数据结构参考财政部公开的[一般企业财务报表格式](https://kjs.mof.gov.cn/zhengcefabu/201905/t20190510_3254992.htm)，按虚构零售企业业务删减并加入管理分析项目，不声明完整准则合规。模拟不含增值税、租赁、合并、外币或递延税；退款按订单月份归集并转回相应成本；所得税与融资参数仅为生成数据的假设。

不能计算尚未分摊的渠道净利润，不能从账面存货金额推算SKU库存件数；周转类与年化指标尚未明确计算口径，不输出余额代替比率。
