# 可视化修复（2026-11-06）

复现问题：“2024年10月的毛利润是多少”。原界面对一行汇总数据仍固定展示340像素表格，并在旁边重复展示没有单位的数字，容易被误认为图表没有加载。

## 本次调整

- 单行数值改为指标卡，支持元、百分比、笔、人、件等已声明单位；金额保留两位小数。分类标签保留，明细与SQL可展开查看。
- 表格高度按真实行数计算，较长结果滚动显示。执行模式、耗时和结构检查状态缩为辅助说明。
- 不同单位的指标不共用一个坐标轴，改用下拉框选择指标；切换复用查询结果，不重新查询或调用模型。财务趋势也采用相同原则。
- 全空数值不生成图表；非有限值不显示为有效KPI；单个月份不伪装成趋势。折线按期间排列。
- 图表使用独立临时文件并读取为图片字节，避免多个查询共用同一个输出文件。

## 数字与口径

该问题沿用既有订单毛利口径，结果为152,350.00元；本次没有修改数据库、SQL计算公式或历史数值。页面明确显示：未扣模拟退款及期间费用。若要扣退款后的财报毛利，请查询“2024年10月财务毛利”或利润表。单个汇总数字不能据此画出期间走势。

## 验证

离线全量回归285项通过，修改文件通过Ruff检查。新增覆盖原始问题的金额卡与折叠明细、金额与百分比混合查询的图表切换和结果复用、空值及负值格式。浏览器实际复测原问题和品类销售额/毛利率切换，截图见同目录“可视化修复-单值结果-20261106.png”。本次没有调用付费模型。
